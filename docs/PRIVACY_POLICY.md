# Privacy Policy

**Last updated:** 2026-07-25

## Overview

Swagger API Auto Tester ("the Extension") is committed to protecting your privacy.
This policy explains what data the extension collects, how it is used, and your rights.

---

## Data Collection

The Extension **does not collect, transmit, or share any personal data.**

All data generated by the extension is:
- Stored **exclusively** in your browser via `chrome.storage.local`
- **Never sent** to any external server, analytics service, or third party
- **Never synchronized** to the cloud (v1.0)
- **Accessible only** within your Chrome browser profile

---

## What Is Stored Locally

The extension stores the following data on your device:

| Data Type | Storage Key | Purpose |
|---|---|---|
| Authentication credentials | `activeAuthCredentials` | Reuse credentials entered in Swagger UI |
| Environment profiles | `environmentProfiles` | Save and switch between API environments |
| Test run history | `testRuns` | Track and compare test executions over time |
| Generated reports | `savedReports` | Store exported reports locally |
| Application settings | `sat_app_config` | Persist user preferences |
| Extension version | `sat_schema_version` | Run storage schema migrations |

---

## Credentials and Tokens

- Authentication tokens (Bearer, API Key, etc.) are stored **locally only**
- Tokens are **masked in logs** (if `maskTokensInLogs` is enabled, which is the default)
- Tokens are **masked in exported reports** (if `maskTokensInReports` is enabled)
- You can clear all stored credentials at any time via **Settings → Clear Auth Data**

---

## API Requests

When you use the extension to run API tests:
- Requests are sent **from your browser** directly to the target API server
- The extension acts as a test runner — it does not proxy or intercept requests
- Request bodies may contain data from the OpenAPI specification examples
- No request data is logged to any external service

---

## Permissions Justification

| Permission | Justification |
|---|---|
| `storage` | Required to save test history, environments, and settings locally |
| `activeTab` | Required to read the current page URL and inject the test sidebar |
| `tabs` | Required to communicate between the popup and the content script |
| `<all_urls>` | Required to execute test requests to any API server from the page's origin |

---

## User Control

You can at any time:
- Clear all stored data: **Settings → Reset All Data**
- Clear history: **History → Clear All Runs**
- Clear credentials: **Settings → Clear Auth Data**
- Uninstall the extension, which removes all associated local storage
